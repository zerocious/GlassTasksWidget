# Glass Tasks Widget

Десктоп-виджет **Tasks ↔ Habits** со стеклянным UI на Electron. Синхронизация с **Google Tasks** или локальный **демо-режим** (mock) без ключей.

Макеты: [`mockups/`](./mockups/). Приложение: [`app/`](./app/).

## Быстрый старт

**Уже собрано** — ярлык на Desktop (`Glass Tasks Widget.lnk`), обычно на `app\dist\win-unpacked\…` или установленный exe.

**Из исходников:**

```powershell
cd C:\Users\User\Desktop\GlassTasksWidget\app
npm install
npm start
```

**Установщик / unpacked:**

```powershell
cd C:\Users\User\Desktop\GlassTasksWidget\app
npm install
$env:CSC_IDENTITY_AUTO_DISCOVERY = "false"
npm run dist    # NSIS → app\dist\Glass Tasks Widget-Setup-1.0.0.exe + ярлык
# или
npm run pack    # app\dist\win-unpacked\ + ярлык
```

После `dist` / `pack` скрипт `scripts/update-desktop-shortcut.ps1` обновляет ярлык на Desktop (и Start Menu). Только ярлык: `npm run shortcut`.

Если ошибка `winCodeSign` / symbolic link — включите **Режим разработчика** Windows и повторите. В конфиге `signAndEditExecutable: false`. Если `app.asar` занят — закройте виджет, удалите `app\dist`, снова `npm run dist`.

| Команда | Результат |
|---------|-----------|
| `npm start` / `npm run dev` | Запуск из исходников |
| `npm run dist` / `npm run build:win` | NSIS-установщик + автоярлык |
| `npm run pack` / `npm run pack:desktop` | `win-unpacked/` + автоярлык |
| `npm run shortcut` | Только обновить ярлык |
| `npm test` | Юнит-тесты (`node:test`, папка `app/test/`) |
| `npm run lint` | ESLint |

Чтобы запустить dev-сборку рядом с установленным виджетом (отдельные настройки, токены и single-instance lock), укажите отдельный профиль:

```powershell
$env:GT_USER_DATA_DIR = "$env:TEMP\gt-dev"
npm start
```

Dev-запуск не перезаписывает существующие ярлыки «Glass Tasks Widget».

## Первый запуск (Google)

Ручной `.env` **не нужен** для обычных пользователей.

1. При старте без ключей открывается мастер «Подключение Google» (или **«Продолжить в демо»**). В нём 4 шага со ссылками прямо на нужные страницы Google Cloud: включить Tasks API → экран согласия → **Publish app** → клиент «Приложение для ПК» с **Download JSON**.
2. Скачанный `client_secret_….json` перетаскивается в мастер (или выбирается кликом, или вставляется целиком в поле Client ID). Есть и ручной ввод Client ID / Secret. Вход в браузере начинается сразу после сохранения.
3. Пока виджет ждёт браузер, есть кнопки «Открыть снова», «Скопировать ссылку» и «Отмена». Если через 30 секунд ответа нет, появляется подсказка с типичными ошибками Google.
4. Ключи хранятся в `data\credentials.json`, зашифрованными через Electron `safeStorage` (DPAPI); если шифрование недоступно, ключи живут только в памяти до выхода (см. «Модель угроз»). `.env`, который писали старые версии, при первом запуске переносится туда и удаляется. Сменить ключи можно позже: Настройки → **Google API ключи**. Если сменился Client ID, старый вход сбрасывается.

Разработчики по-прежнему могут скопировать `app/.env.example` → `.env` (читаются только `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `OAUTH_REDIRECT_PORT`; ключи из `credentials.json` имеют приоритет). Значения из `.env` и из переменных оболочки забираются один раз в модуль `lib/config.js` и удаляются из `process.env`.

## Возможности

- **Tasks ↔ Habits** — табы, слайд, свайп; у привычек week-strip стриков и иконки по ключевым словам в названии
- **Добавление** — поле внизу панели (Google API или mock). Срок можно написать прямо в названии: «Позвонить маме завтра в 18:30», «Отчёт в пятницу», «Сдать до 12.10», «через 3 дня», «Зарядка каждый день 7:00» — фраза уходит из названия и становится сроком, временем или повтором
- **ПКМ по строке** — изменить, заметки, **срок** (сегодня / завтра / через неделю / дата / без срока), время, повтор, подзадача, удалить
- **Отмена** — после удаления 5 секунд висит «… удалена · Отменить»; у повторяющейся задачи можно отменить сдвиг на следующий раз
- **Фоновая синхронизация** — раз в 3 минуты, при возврате фокуса и при появлении сети; не трогает список, пока вы что-то редактируете
- **Сбои сети** — запросы к Google повторяются при 429/5xx и обрывах соединения (создание задачи — только если Google явно отказал, чтобы не получить дубль)
- **Сроки** — today / overdue, сортировка; время из due (если не «полночь UTC») или из notes (`14:30`, `в 14:30`, `time: …`, `время …`)
- **Офлайн-кэш** — при сбое сети последние Google-данные + бейдж «офлайн»
- **Автопалитра с обоев** — акцент из wallpaper Windows; тумблер и кнопка «С обоев»
- **Трей** — показать/скрыть, вид, добавить, выход (кнопки **–** / **×** только скрывают в трей)
- **Шрифт** — **Geist Mono** (локальные файлы в `src/fonts/`)

### Напоминания

- **Точное время:** для открытых задач с локальным date+time (due не midnight-UTC, либо время из notes + дата due / сегодня) — one-shot таймер (горизонт 24 ч). Тост: «Пора: Title (14:30)».
- **Sweep ~45 мин:** safety net для date-only (today/overdue), просроченных timed и незакрытых привычек (без часов).
- Первый проход ~через 8 с после старта; таймеры пересобираются после refresh/мутаций; сбрасываются при выключении напоминаний / quit.
- Один и тот же пункт не спамит повторно в тот же день (`reminders.json`).
- **«Проверить»** — принудительный тост (игнорирует «уже уведомляли сегодня»).
- Если тостов нет: Параметры Windows → Система → Уведомления — разрешите приложение; отключите Фокусировку внимания.

### Привычки: ежедневный сброс

- Раз в локальные сутки (и при старте, если день новый): в списке Habits все `completed` → `needsAction` (Google API или mock). Стрики локальные — не трогаем.
- Тумблер в настройках (по умолчанию вкл.); дата последнего сброса — `lastHabitsResetDate` в `settings.json`.

### Автообновления

- Только **упакованная** сборка (`app.isPackaged`); `npm start` проверки пропускает.
- Провайдер: GitHub Releases (`zerocious/GlassTasksWidget`). NSIS `dist` пишет `latest.yml` + blockmap.
- Публикация: создайте GitHub Release с артефактами из `npm run dist` (Setup.exe, `.blockmap`, `latest.yml`). Без опубликованного релиза проверка ничего не найдёт.
- Сборка **без подписи** (`signAndEditExecutable: false`): SmartScreen может ругаться; updater отключает проверку publisher signature, иначе обновления не встанут. Для продакшена лучше code signing.

## Google Cloud

1. Включите **Google Tasks API**.
2. Экран согласия: тип **External**. Затем **Audience → Publish app**. В статусе **Testing** Google выдаёт refresh-токены на 7 дней, и вход слетает раз в неделю. Для личного использования (до 100 человек) проверка приложения не нужна. Пользователи увидят предупреждение «приложение не проверено» и пройдут его через «Дополнительно».
3. OAuth-клиент типа **Desktop app** («Приложение для ПК»). Скачайте JSON сразу при создании: позже Google секрет не показывает.
4. Redirect URI регистрировать не нужно. Виджет слушает `http://127.0.0.1:<свободный порт>/oauth2callback`. Фиксированный порт можно задать в ручном вводе ключей; если он занят, виджет возьмёт свободный. Клиент типа «Веб-приложение» не поддерживается.
5. В Google Tasks создайте списки с именами из `app/config.json` (по умолчанию `Tasks`, `Habits`) и нажмите ↻.

OAuth: **state** + **PKCE (S256)**. Refresh-токен хранится зашифрованным (или только в памяти, если шифрование недоступно); «Выйти» отзывает его в Google.

Ошибки входа и настройки показываются по-русски, с кнопкой на нужную страницу консоли. Так обрабатываются `access_denied`, удалённый или неверный клиент, выключенный Tasks API, запрет администратора Workspace и занятый порт. Для отладки без браузера есть `GT_OAUTH_NO_BROWSER=1`: ссылка входа не открывается, а пишется в лог.

## Где лежат данные

Папка данных: **`%APPDATA%\glass-tasks-widget\data\`** (установленная версия) или `app/data/` при запуске из исходников. Если задан `GT_USER_DATA_DIR`, то при запуске из исходников это `<GT_USER_DATA_DIR>\data\`, и изолированный профиль не делит данные с рабочей папкой `app/data`.

| Файл | Что внутри | Защита | Зачем и что будет, если удалить |
|------|-----------|--------|---------------------------------|
| `tokens.json` | OAuth-токены Google (refresh и access) | **шифруется** Electron `safeStorage` (DPAPI) | вход в Google; без файла нужно войти заново |
| `credentials.json` | Client ID и Client Secret | **шифруется** | ключи приложения; без файла откроется мастер подключения |
| `offline-cache.json` | копия последнего ответа Google: названия задач, заметки, сроки (личные данные) | **шифруется**, пишется отложенно | показывается без сети; безопасно удалять, обновится при синхронизации |
| `streaks.json` (+ `.bak`) | история отметок привычек: id привычки и даты | открытый JSON | **ценные данные**, нигде больше не хранятся. Не удалять |
| `settings.json` (+ `.bak`) | тема, размер, прозрачность, горячие клавиши, позиция окна | открытый JSON | при удалении вернутся значения по умолчанию |
| `reminders.json` | какие напоминания уже показаны сегодня | открытый JSON | одноразовые тосты могут повториться |
| `mock-items.json` (+ `.bak`) | списки демо-режима (единственная копия задач, добавленных в демо) | открытый JSON | демо вернётся к исходным спискам |
| `backups\` | недельные, ручные и предымпортные копии (`weekly-…`, `manual-…`, `pre-import-…`), а в `backups\migrations\` исходники файлов перед обновлением формата | открытый JSON, **без токенов и ключей** | копии на случай сбоя |
| `*.corrupt-<время>` | повреждённый файл, который приложение убрало в сторону | как у исходного | можно удалить после проверки |

Логи лежат отдельно, в `%APPDATA%\glass-tasks-widget\logs\`, и в папку данных не входят.

**Почему `streaks.json` и `settings.json` не шифруются.** В них нет секретов: у привычек только непрозрачный id из Google Tasks и даты. Шифрование DPAPI привязано к учётной записи Windows и компьютеру: такой файл нельзя восстановить из копии на другом ПК, а ради защиты данных, которые никого не интересуют, терять историю привычек не стоит. Названия и заметки задач в эти файлы не попадают. **Демо-режим** хранит названия в открытом `mock-items.json`: для личных задач подключите Google.

**Почему кэш шифруется.** В `offline-cache.json` лежат названия и заметки задач. Замер (`node scripts/bench-storage.js`, 200 задач ≈ 70 КБ, шифрование AES-GCM как замена DPAPI): сериализация 0,15 мс, шифрование и запись ≈ 1,1 мс, чтение и расшифровка ≈ 0,5 мс; для 1000 задач ≈ 4 мс. Изменение задачи этих затрат не несёт: оно обновляет только память и ставит таймер (≈ 0,00 мс), на диск кэш пишется не чаще раза в 1,5 с, а при выходе дописывается. Цифры с настоящим DPAPI снимите на Windows командой `npx electron scripts/bench-storage.js`. Без `safeStorage` кэш живёт только в памяти: это копия данных Google, ничего не теряется.

### Модель угроз

Защищено:

- **другие пользователи Windows** на том же компьютере и копия папки данных, унесённая на другую машину или в другую учётную запись: токены, ключи и кэш зашифрованы DPAPI;
- **утечка через экспорт, резервную копию, коммит или логи диагностики**: в экспорт и копии токены и секрет не попадают (перед записью текст проверяется на совпадение с действующими секретами), `data/` целиком в `.gitignore`;
- **утечка через окружение**: `GOOGLE_CLIENT_SECRET` не лежит в `process.env` и не наследуется дочерними процессами (тосты PowerShell, установщик обновлений); переменные из оболочки или dev `.env` читаются один раз и удаляются из окружения;
- **порча и потеря**: запись атомарная, повреждённый файл не перезаписывается, а убирается в `*.corrupt-…`; для `streaks.json`, `settings.json`, `mock-items.json` восстанавливается последняя хорошая копия (`.bak`); перед обновлением формата исходный файл копируется в `backups\migrations\`; раз в неделю создаётся резервная копия.

**Не защищено** (ограничение DPAPI и `safeStorage`):

- **любой процесс, запущенный от того же пользователя Windows**, может расшифровать токены: DPAPI не разделяет приложения. Вредоносная программа под вашей учётной записью получит доступ к Google Tasks, пока вы не отзовёте доступ (в виджете «Выйти» или на myaccount.google.com/permissions);
- человек с вашим паролем Windows или с полным доступом к диску без BitLocker;
- содержимое памяти работающего виджета.

Client Secret Desktop-приложения Google и так не считает секретом (его знает каждый, у кого есть установщик), поэтому пункт про окружение это гигиена, а не граница безопасности.

**Если `safeStorage` недоступен** (редко: сломанный профиль Windows, запуск из исходников на Linux без keyring), токены и ключи **не пишутся на диск открытым текстом**: они живут в памяти до выхода, виджет предупреждает событием `data:event` / записью в отчёте, и после перезапуска нужно войти снова. Старый открытый файл с токеном остаётся на месте до первой записи новых токенов (чтобы обновление не разлогинило), затем удаляется, а в отчёте помечается как `plaintext`. Только для разработки: `GT_ALLOW_PLAINTEXT_SECRETS=1` разрешает открытый файл (в установленной версии игнорируется).

### Сбои и версии формата

- У каждого файла есть `schemaVersion`. Файл без номера считается версией 0 (так писали прошлые релизы). Старый файл переводится на текущую версию по шагам; перед этим его копия сохраняется в `backups\migrations\` (хранятся три последние на файл; для файлов с токенами и кэшем копий нет, чтобы не оставлять открытый текст). Файл от **более новой** версии приложения копируется один раз и не понижается.
- Повреждённый `streaks.json` / `settings.json` / `mock-items.json`: файл уходит в `*.corrupt-…` (хранятся три последних), содержимое восстанавливается из `.bak`. Если и копия повреждена, данные сбрасываются, а виджет сообщает об ошибке. Удалённый вручную файл не «воскрешается» из `.bak`: так работает сброс.
- Недокончённые `*.tmp` после сбоя питания удаляются при старте.
- Если файл не удалось сохранить (диск полон, нет прав), ошибка не теряется: она показывается как событие `write-failed`, а операция завершается ошибкой.
- Всё, что произошло с данными за сессию (восстановление из копии, миграция, режим «только в памяти»), попадает в `getStorageReport()` для диагностики и приходит окну виджета событием `data:event`.

### История привычек и рост файла

`streaks.json` хранит отметки не по строке на день, а **отрезками подряд идущих дней**: привычка, выполняемая каждый день три года, занимает одну запись. Дни старше **5 лет** (1830 дней) не удаляются, а сворачиваются в `archive` (число выполненных дней по месяцам); календарь показывает дни за последние 5 лет. Прежний молчаливый лимит в 800 дат убран. При повторном импорте одного и того же файла счётчики архива не раздуваются (берётся максимум).

### Резервные копии, экспорт, импорт

- **Недельная копия**: при запуске (и раз в 12 часов, пока виджет работает) создаётся `backups\weekly-ГГГГ-ММ-ДД.json`, если последней больше 7 дней; хранятся 8 недельных, 10 ручных и 5 предымпортных. Пустая установка копий не создаёт.
- **Экспорт JSON**: настройки, история привычек, демо-списки (если был демо-режим); по желанию хвост логов с вырезанными токенами. **Токенов и секрета в файле никогда нет.**
- **Экспорт CSV**: задачи и привычки (`list, title, status, due, notes, id, parent_id`), UTF-8 с BOM для Excel. Ячейки, начинающиеся на `=`, `+`, `-`, `@`, получают ведущий апостроф, чтобы Excel не выполнил их как формулы.
- **Импорт**: файл проверяется (размер, формат, версия), показывается подтверждение, перед импортом создаётся `pre-import-…`. Данные **объединяются**: даты привычек складываются, локальные не удаляются, демо-элементы добавляются по id. Из настроек переносятся тема, размер, прозрачность, акцент, напоминания и подобные; горячие клавиши, автозапуск и позиция окна остаются прежними. Если настройки применены, виджет перезапускается.
- Диалоги выбора файла и подтверждения показывает главный процесс.

### Удалить все мои данные

Удаляет: доступ Google (токен отзывается у Google), ключи Client ID/Secret, кэш, историю привычек, настройки, напоминания, демо, резервные копии, старый `.env`, данные окна (кэш, localStorage и т. д. через `session.clearStorageData`), запись автозапуска. После этого виджет перезапускается. Остаются: логи, ваши экспортированные файлы, задачи в аккаунте Google и сами файлы программы.

### При удалении программы

По умолчанию деинсталлятор данные **не трогает** (`nsis.deleteAppDataOnUninstall` = `false` в `package.json`): переустановка «удалить и поставить заново» не стирает историю привычек. Чтобы удалять `%APPDATA%\glass-tasks-widget` вместе с программой, поставьте `true` в `build.nsis` и пересоберите установщик. Проверено по шаблонам electron-builder 25.1.8: удаляется вся папка профиля, включая логи, а при автообновлении (`--updated`) данные не удаляются никогда. Разово удалить данные можно запуском деинсталлятора с ключом `--delete-app-data`. Перед удалением удобнее нажать «Удалить все мои данные» в самом виджете: это ещё и отзовёт доступ в Google.

### Сброс вручную

Закройте виджет и удалите нужный файл: `settings.json` (настройки), `reminders.json`, `offline-cache.json` (безопасно), `tokens.json` (выход), `credentials.json` (ключи). Для `streaks.json`, `settings.json` и `mock-items.json` удаляйте файл вместе с его `.bak`. Всё сразу: «Удалить все мои данные» или удалить папку `data`.

### Для разработчиков

`GT_USER_DATA_DIR` (профиль и папка данных), `GT_ALLOW_PLAINTEXT_SECRETS=1`, `GT_OAUTH_NO_BROWSER=1`. Тесты работают во временных папках через `setDataRootForTests` (см. `test/helpers/tmp-data.js`) и не трогают `app/data`. `node scripts/bench-storage.js` измеряет стоимость кэша.

## Отложено / ограничения

- Google Tasks чаще отдаёт **только дату** (без времени) — время в виджете из notes или нестандартного due
- Стрики привычек **локальные** (нет облачной синхронизации); резервные копии лежат на том же диске, для защиты от его потери сохраняйте экспорт в другое место
- История привычек по дням хранится 5 лет, более старые дни — только счётчиками по месяцам
- Редактор горячих клавиш в UI
- Нативный Windows Widgets provider / Tauri
