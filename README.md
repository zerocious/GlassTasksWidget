# Glass Tasks Widget

Десктоп-виджет **Tasks ↔ Habits** со стеклянным UI на Electron. Синхронизация с **Google Tasks** или локальный **демо-режим** (mock) без ключей.

Макеты: [`mockups/`](./mockups/). Приложение: [`app/`](./app/).

## Быстрый старт

**Уже собрано** — ярлык на Desktop (`Glass Tasks Widget.lnk`), обычно на `app\dist\win-unpacked\…` или установленный exe.

**Из исходников:**

```powershell
cd C:\Users\User\Desktop\GlassTasksWidget\app
npm install
npm start
```

**Установщик / unpacked:**

```powershell
cd C:\Users\User\Desktop\GlassTasksWidget\app
npm install
$env:CSC_IDENTITY_AUTO_DISCOVERY = "false"
npm run dist    # NSIS → app\dist\Glass Tasks Widget-Setup-1.0.0.exe + ярлык
# или
npm run pack    # app\dist\win-unpacked\ + ярлык
```

После `dist` / `pack` скрипт `scripts/update-desktop-shortcut.ps1` обновляет ярлык на Desktop (и Start Menu). Только ярлык: `npm run shortcut`.

Если ошибка `winCodeSign` / symbolic link — включите **Режим разработчика** Windows и повторите. В конфиге `signAndEditExecutable: false`. Если `app.asar` занят — закройте виджет, удалите `app\dist`, снова `npm run dist`.

| Команда | Результат |
|---------|-----------|
| `npm start` / `npm run dev` | Запуск из исходников |
| `npm run dist` / `npm run build:win` | NSIS-установщик + автоярлык |
| `npm run pack` / `npm run pack:desktop` | `win-unpacked/` + автоярлык |
| `npm run shortcut` | Только обновить ярлык |
| `npm test` | Юнит-тесты (`node:test`, папка `app/test/`) |
| `npm run lint` | ESLint |

Чтобы запустить dev-сборку рядом с установленным виджетом (отдельные настройки, токены и single-instance lock), укажите отдельный профиль:

```powershell
$env:GT_USER_DATA_DIR = "$env:TEMP\gt-dev"
npm start
```

Dev-запуск не перезаписывает существующие ярлыки «Glass Tasks Widget».

## Первый запуск (Google)

Ручной `.env` **не нужен** для обычных пользователей.

1. При старте без ключей открывается мастер «Подключение Google» (или **«Продолжить в демо»**). В нём 4 шага со ссылками прямо на нужные страницы Google Cloud: включить Tasks API → экран согласия → **Publish app** → клиент «Приложение для ПК» с **Download JSON**.
2. Скачанный `client_secret_….json` перетаскивается в мастер (или выбирается кликом, или вставляется целиком в поле Client ID). Есть и ручной ввод Client ID / Secret. Вход в браузере начинается сразу после сохранения.
3. Пока виджет ждёт браузер, есть кнопки «Открыть снова», «Скопировать ссылку» и «Отмена». Если через 30 секунд ответа нет, появляется подсказка с типичными ошибками Google.
4. Ключи хранятся в `data\credentials.json`, зашифрованными через Electron `safeStorage` (DPAPI). Если шифрование недоступно, ключи хранятся только в памяти до закрытия виджета (см. «Где лежат данные»). `.env`, который писали старые версии, при первом запуске переносится в `credentials.json` и удаляется. Сменить ключи можно позже: Настройки → **Google API ключи**. Если сменился Client ID, старый вход сбрасывается.

Разработчики по-прежнему могут скопировать `app/.env.example` → `.env` (читаются только `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `OAUTH_REDIRECT_PORT`; ключи из `credentials.json` имеют приоритет).

## Возможности

- **Tasks ↔ Habits** — табы, слайд, свайп; у привычек week-strip стриков и иконки по ключевым словам в названии
- **Добавление** — поле внизу панели (Google API или mock). Срок можно написать прямо в названии: «Позвонить маме завтра в 18:30», «Отчёт в пятницу», «Сдать до 12.10», «через 3 дня», «Зарядка каждый день 7:00» — фраза уходит из названия и становится сроком, временем или повтором
- **ПКМ по строке** — изменить, заметки, **срок** (сегодня / завтра / через неделю / дата / без срока), время, повтор, подзадача, удалить
- **Отмена** — после удаления 5 секунд висит «… удалена · Отменить»; у повторяющейся задачи можно отменить сдвиг на следующий раз
- **Фоновая синхронизация** — раз в 3 минуты, при возврате фокуса и при появлении сети; не трогает список, пока вы что-то редактируете
- **Сбои сети** — запросы к Google повторяются при 429/5xx и обрывах соединения (создание задачи — только если Google явно отказал, чтобы не получить дубль)
- **Сроки** — today / overdue, сортировка; время из due (если не «полночь UTC») или из notes (`14:30`, `в 14:30`, `time: …`, `время …`)
- **Офлайн-кэш** — при сбое сети последние Google-данные + бейдж «офлайн»
- **Автопалитра с обоев** — акцент из wallpaper Windows; тумблер и кнопка «С обоев»
- **Трей** — показать/скрыть, вид, добавить, выход (кнопки **–** / **×** только скрывают в трей)
- **Шрифт** — **Geist Mono** (локальные файлы в `src/fonts/`)

### Напоминания

- **Точное время:** для открытых задач с локальным date+time (due не midnight-UTC, либо время из notes + дата due / сегодня) — one-shot таймер (горизонт 24 ч). Тост: «Пора: Title (14:30)».
- **Sweep ~45 мин:** safety net для date-only (today/overdue), просроченных timed и незакрытых привычек (без часов).
- Первый проход ~через 8 с после старта; таймеры пересобираются после refresh/мутаций; сбрасываются при выключении напоминаний / quit.
- Один и тот же пункт не спамит повторно в тот же день (`reminders.json`).
- **«Проверить»** — принудительный тост (игнорирует «уже уведомляли сегодня»).
- Если тостов нет: Параметры Windows → Система → Уведомления — разрешите приложение; отключите Фокусировку внимания.

### Привычки: ежедневный сброс

- Раз в локальные сутки (и при старте, если день новый): в списке Habits все `completed` → `needsAction` (Google API или mock). Стрики локальные — не трогаем.
- Тумблер в настройках (по умолчанию вкл.); дата последнего сброса — `lastHabitsResetDate` в `settings.json`.

### Автообновления

- Только **упакованная** сборка (`app.isPackaged`); `npm start` проверки пропускает.
- Провайдер: GitHub Releases (`zerocious/GlassTasksWidget`). NSIS `dist` пишет `latest.yml` + blockmap.
- Публикация: создайте GitHub Release с артефактами из `npm run dist` (Setup.exe, `.blockmap`, `latest.yml`). Без опубликованного релиза проверка ничего не найдёт.
- Сборка **без подписи** (`signAndEditExecutable: false`): SmartScreen может ругаться; updater отключает проверку publisher signature, иначе обновления не встанут. Для продакшена лучше code signing.

## Google Cloud

1. Включите **Google Tasks API**.
2. Экран согласия: тип **External**. Затем **Audience → Publish app**. В статусе **Testing** Google выдаёт refresh-токены на 7 дней, и вход слетает раз в неделю. Для личного использования (до 100 человек) проверка приложения не нужна. Пользователи увидят предупреждение «приложение не проверено» и пройдут его через «Дополнительно».
3. OAuth-клиент типа **Desktop app** («Приложение для ПК»). Скачайте JSON сразу при создании: позже Google секрет не показывает.
4. Redirect URI регистрировать не нужно. Виджет слушает `http://127.0.0.1:<свободный порт>/oauth2callback`. Фиксированный порт можно задать в ручном вводе ключей; если он занят или зарезервирован Windows (Hyper-V, WSL, Docker), виджет возьмёт свободный. Клиент типа «Веб-приложение» работает только с закреплённым портом, который точно указан в Authorized redirect URIs (так работали старые установки с портом 42813, он сохраняется). Файл `client_secret.json` принимается только от клиентов «Приложение для ПК».
5. В Google Tasks создайте списки с именами из `app/config.json` (по умолчанию `Tasks`, `Habits`) и нажмите ↻.

OAuth: **state** + **PKCE (S256)**. Refresh-токен хранится зашифрованным; «Выйти» отзывает его в Google.

Ошибки входа и настройки показываются по-русски, с кнопкой на нужную страницу консоли. Так обрабатываются `access_denied`, удалённый или неверный клиент, выключенный Tasks API, запрет администратора Workspace и занятый порт. Для отладки без браузера есть `GT_OAUTH_NO_BROWSER=1`: ссылка входа не открывается, а пишется в лог.

### Файлы

| Файл | Что внутри | Шифрование | Защита от порчи | Как сбросить |
|------|------------|------------|-----------------|--------------|
| `tokens.json` | Вход в Google (refresh-токен) | safeStorage; без него — только в памяти | — | «Выйти» (токен отзывается в Google) |
| `credentials.json` | Client ID и Client Secret | safeStorage; без него — только в памяти | — | Настройки → Google API ключи |
| `offline-cache.json` | Последние задачи из Google: названия, заметки, сроки | safeStorage; без него — только в памяти | Это кэш: при порче пересоздаётся из Google | «Выйти» или удалить файл |
| `streaks.json` | История привычек по дням — **единственная копия**, в Google её нет | нет (см. ниже) | `streaks.json.bak` + недельные копии | Удалить `streaks.json` и `streaks.json.bak` |
| `settings.json` | Тема, размер, позиция окна, горячие клавиши | нет | `settings.json.bak` + недельные копии | Удалить `settings.json` и `settings.json.bak` |
| `reminders.json` | Какие напоминания уже показаны сегодня | нет | — | Удалить файл |
| `mock-items.json` | Задачи демо-режима | нет | — | Удалить файл |
| `backups\` | Недельные и ручные копии настроек и истории привычек | нет | — | Удалить папку |

Секреты и задачи шифруются: в них ключи доступа и личный текст. Настройки и история привычек — это даты и идентификаторы без названий, поэтому они хранятся открыто и их можно прочитать или поправить руками.

Каждый файл пишется атомарно: временный файл сбрасывается на диск (fsync), затем заменяет старый. Обрыв питания посреди записи оставляет прежнюю версию, а не пустой файл. У каждого файла есть поле `schemaVersion`. У зашифрованных оно продублировано в «конверте» `{"format":"glass-tasks/safeStorage@1","schemaVersion":…,"data":"…"}`.

### Модель угроз

Шифрование — Electron `safeStorage`. На Windows ключ защищён DPAPI текущей учётной записи.

- **Защищает от:** других пользователей этого ПК; чтения диска или копии `%APPDATA%` на другом компьютере (облачный бэкап, перенос профиля, украденный диск без пароля Windows); случайной отправки папки `data` кому-то (например, вместе с отчётом об ошибке).
- **Не защищает от:** программ, запущенных под той же учётной записью Windows: DPAPI расшифрует для них то же, что и для виджета. Не защищает и от администратора, знающего ваш пароль, и от дампа памяти работающего виджета. `mode 0o600` на Windows ничего не меняет: доступ к `%APPDATA%` и так ограничен ACL профиля.
- **Перенос на другой ПК:** зашифрованные файлы там не откроются. Виджет попросит войти заново, кэш соберётся заново. Историю привычек и настройки переносите через экспорт.
- SSD и NTFS не гарантируют затирание старых блоков. Открытая копия, которую писала старая версия, могла физически остаться на диске до перезаписи.

**Если шифрование недоступно** (бывает на Linux без связки ключей или при сбое DPAPI), секреты и кэш задач **не пишутся открытым текстом**. Они живут в памяти до закрытия виджета: после перезапуска нужно войти снова. Виджет показывает предупреждение, а отчёт диагностики пишет «НЕДОСТУПНО». Старый файл, который прежняя версия записала открытым текстом, не удаляется (иначе слетит вход). В отчёте он помечается «ОТКРЫТЫМ ТЕКСТОМ» и шифруется при первой возможности. Разработчик может разрешить открытую запись переменной `GT_ALLOW_PLAINTEXT_SECRETS=1`; в собранной программе она игнорируется.

**Выход из аккаунта.** Refresh-токен отзывается запросом к `https://oauth2.googleapis.com/revoke`, токен идёт в теле POST, а не в адресе: адреса оседают в журналах прокси и в текстах сетевых ошибок. Если отозвать не удалось, в журнал пишется только код ошибки (`revoke failed (ENOTFOUND)`), локальная копия всё равно удаляется, а вызывающий код получает статус `failed`, чтобы предложить удалить доступ вручную.

**Горячие клавиши** проверяются при чтении и сохранении `settings.json`: нужен модификатор Ctrl, Alt или Win (Shift не считается, он печатает символы); системные и редакторские сочетания (`Ctrl+C/V/X/Z/Y/A`, `Alt+F4`, `Alt+Tab`, `Ctrl+Alt+Delete` и т. п.) не принимаются ни в каком написании (`ctrl+c`, `CmdOrCtrl+C`). Одиночные клавиши разрешены только для F13–F24. Иначе действует сочетание по умолчанию.

Ключи Google не попадают в `process.env`, иначе их унаследовали бы дочерние процессы (например, PowerShell для тостов). `.env` и переменные окружения разработчика читаются один раз при старте, после чего переменные удаляются из окружения.

### Сбои: что происходит и что видит пользователь

| Ситуация | Поведение |
|----------|-----------|
| Файл повреждён (не JSON, нули после сбоя) | Переименовывается в `*.corrupt-<время>`. У `streaks.json` и `settings.json` данные восстанавливаются из `.bak`, у остальных берутся значения по умолчанию. Пользователь видит предупреждение. Копия повреждённого кэша задач хранится зашифрованной |
| Повреждён `tokens.json` или `credentials.json` | Файл удаляется (в открытой копии мог бы остаться обрывок токена или ключа), виджет просит войти или загрузить ключи снова |
| Файл старого формата (нет `schemaVersion`) | Копируется в `<файл>.v0.bak`, затем мигрирует при старте. У зашифрованных файлов открытой копии нет |
| Файл от более новой версии | Копируется в `<файл>.v<N>.bak`, используется как есть, показывается совет обновиться |
| Файл занят антивирусом или другой программой | До трёх коротких повторов (не дольше 0,25 с), дальше минуту без ожиданий, чтобы окно не подвисало. Используется `.bak` или значения по умолчанию. Перед первой перезаписью непрочитанный файл копируется в `*.unread-<время>.bak` (у кэша задач — зашифрованно), а пока он занят, запись отклоняется |
| Не удалось записать (нет места, нет прав) | Операция завершается ошибкой, пользователь видит причину |
| Зашифрованный файл не открывается | Файл не трогается, до перезапуска используются пустые данные |
| Временные `*.tmp` после сбоя посреди записи | Удаляются при следующем запуске (старше 10 минут) |

Все такие события собираются в отчёте диагностики (`lib/storage-status.js`) и приходят в виджет событием `data:storage-issue`.

### Рост данных

`streaks.json` хранит дни как битовые маски месяцев (`"2026-10": 2147483647`). Ежедневная привычка занимает около 20 байт в месяц вместо ~400 при списке дат. 20 ежедневных привычек за 10 лет — около 50 КБ вместо ~1,5 МБ. Хранится 120 последних месяцев. Более старые дни удаляются при сохранении, привычка без отметок в этом окне исчезает из файла. Раньше файл рос без предела, а при 800 датах молча обрезался.

`offline-cache.json` пишется не на каждое изменение, а через ~0,4 с после последнего (серия изменений даёт одну запись) и при выходе. Статистика привычек в кэш больше не копируется. Замеры `node scripts/bench-storage.js`, медиана из 25 прогонов:

| Задач | Файл было → стало | Изменение задачи: было → стало | Отложенная запись (шифр + fsync) | Чтение при старте |
|---:|---:|---:|---:|---:|
| 50 | 214 → 45 КБ | 1,9 → 0,02 мс | 1,8 мс | 0,4 мс |
| 200 | 327 → 175 КБ | 3,1 → 0,01 мс | 3,6 мс | 2,7 мс |
| 1000 | 932 → 871 КБ | 4,9 → 0,02 мс | 14 мс | 8 мс |

Шифрование здесь — AES-256-GCM в Node как замена `safeStorage`. С настоящим `safeStorage` Electron 33 цифры того же порядка. На Windows с DPAPI их можно получить командой `npx electron scripts/bench-storage.js`; скрипт работает только во временной папке.

### Резервные копии, экспорт и импорт

- **Недельные копии:** раз в 7 дней (первая проверка через минуту после старта) в `data\backups\backup-<дата>-<время>-weekly.json`. Хранятся 8 последних недельных, 8 ручных и 3 копии перед импортом. В копию входят настройки (без позиции окна) и история привычек. Токены, ключи и задачи в неё не попадают.
- **Экспорт JSON:** настройки и история привычек с названиями привычек. Логи (до 1 МБ, с начала строки) добавляются только по явному запросу: в них может попасть текст задач из сообщений об ошибках. Токены и Client Secret не экспортируются никогда. Готовый текст дополнительно чистится от всего, что похоже на токен или код входа: `ya29.…`, `1//…` и его URL-кодированная форма, `GOCSPX-…`, JWT, `Bearer …`, `?token=`/`?code=`, поля `refresh_token` и т. п. Если в тексте остаётся действующий секрет или его фрагмент от 16 символов, экспорт не записывается.
- **CSV задач:** открытые и последние выполненные задачи и привычки, как в виджете. Разделитель `;`, кодировка UTF-8 с BOM, чтобы русский Excel открыл файл без настройки. Знаки `=`, `+`, `-`, `@` в начале ячейки и после любого символа, с которого Excel может начать новое поле (`,`, `;`, табуляция, перевод строки), получают апостроф: формула не выполнится, даже если Excel с английской локалью разделит строку по запятым. Из-за этого внутри многострочных заметок перед такими строками виден апостроф. Точная копия данных — экспорт JSON.
- **Импорт:** принимает файлы экспорта и копии из `backups`. Файл проверяется: формат, версия, размер до 20 МБ (читается с ограничением, без доверия к размеру из файловой системы), не больше 500 привычек и 400 000 отметок, даты только в пределах хранимых 10 лет и не позже завтрашнего дня. Дни привычек **объединяются**: импорт ничего не удаляет. Настройки из файла заменяют текущие, кроме позиции окна, автозапуска и горячих клавиш: файл не может включить автозапуск или занять клавиши во всей системе. Перед импортом автоматически делается копия `…-pre-import.json`.
- Файлы выбираются в стандартных диалогах Windows, которые открывает главный процесс.

### Удалить все мои данные

Команда спрашивает подтверждение в системном диалоге и удаляет:

- вход Google (токен сначала отзывается в Google);
- ключи;
- кэш задач, историю привычек, настройки, напоминания, резервные копии;
- `%APPDATA%\glass-tasks-widget\.env` от старых версий;
- хранилище Chromium (`session.clearStorageData`, кэш).

Удаляются только файлы, которые создаёт сам виджет. Посторонние файлы в папке `data` остаются, как и сама папка, если в ней что-то осталось. Папка-ссылка (symlink или junction) не обрабатывается вовсе. Автозапуск выключается. После удаления любая запись блокируется, и виджет перезапускается с чистого листа. Задачи в самом Google Tasks не затрагиваются.

Если отозвать доступ в Google не удалось (нет сети, тайм-аут, недоступно шифрование), перед перезапуском появится окно с кнопкой, открывающей https://myaccount.google.com/permissions: там доступ Glass Tasks удаляется вручную. Логи (`logs\`) и служебные файлы Chromium в корне профиля остаются; об этом сказано и в окне подтверждения. Чтобы убрать всё до последнего байта, удалите программу с удалением данных (см. ниже) или вручную удалите `%APPDATA%\glass-tasks-widget` после выхода из виджета.

**При удалении программы** деинсталлятор убирает запись автозапуска из `HKCU\…\Run`, иначе она продолжала бы указывать на удалённый exe, который кто-то мог бы подложить заново. Ещё он спрашивает: «Удалить также ваши данные?». По умолчанию выбрано «Нет». При «Да» удаляется `%APPDATA%\glass-tasks-widget` целиком. При обновлении и при тихом удалении (`/S`) вопрос не задаётся и данные остаются; чтобы удалить их в тихом режиме, добавьте ключ `--delete-app-data`. Опция electron-builder `deleteAppDataOnUninstall` намеренно выключена: она стирает историю привычек без вопроса, даже если программу переустанавливают.

## Структура

```
GlassTasksWidget/
  app/
    electron/   # main (окно, трей, IPC), data-ipc (данные пользователя), notifications, reminders, updater, preload
    lib/        # Google API, task-parse (время/повторы), list-ops, dates, streaks, settings, mock, offline, wallpaper
                # storage-*: версии и миграции файлов, копии, экспорт/импорт, удаление данных, статус
    test/       # node:test
    src/        # UI + Geist Mono fonts
    build/      # icon
    dist/       # вывод сборки
  mockups/
  README.md
```

## Отложено / ограничения

- Google Tasks чаще отдаёт **только дату** (без времени) — время в виджете из notes или нестандартного due
- Стрики привычек **локальные** (нет облачной синхронизации)
- Редактор горячих клавиш в UI
- Нативный Windows Widgets provider / Tauri
