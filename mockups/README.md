# Макеты десктоп-виджетов (визуал + HTML-демо)

Утверждённый концепт реализован в `../app/` (Electron always-on-top).

## Выбранный концепт

- **Один блок** на экране: Tasks или Habits
- Плавный слайд Tasks ↔ Habits
- Данные: **Google Tasks** (списки Tasks и Habits), без Todoist
- Glassmorphism, акцент `#C4122E`
- Стрик: week-strip 7 day-pills + бейдж «N дн.»
